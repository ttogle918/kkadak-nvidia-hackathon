# /logger — 세션 로그 저장 (마무리 없이)

지금까지의 대화를 `docs/session_log/` 에 기록한다. `/done` 과 **같은 파일 형식**이고, 커밋 확인·결정 정합성 점검은 하지 않는다.

## 파일 이름

`YYYY-MM-DD_HHMM_주요작업.md` — 예: `2026-10-04_1530_스킬-에이전트-가이드-정리.md`

- 날짜·시각은 `date '+%Y-%m-%d_%H%M'` 로 얻는다 (지어내지 않는다)
- 주요작업은 이 세션에서 **가장 중요했던 일 한 가지**를 한국어 2~6단어로, 공백은 `-`, 파일명에 못 쓰는 문자(`/ : * ? " < > |`)는 뺀다
- **같은 세션에서 이미 만든 로그가 있으면 새로 만들지 말고 그 파일을 갱신**한다 (대화에서 직전에 쓴 경로를 쓴다). 이름의 주요작업이 달라졌으면 파일명만 바꾼다(`git mv` 가 아니라 `mv` — 아직 커밋 전일 수 있다)

## 기록할 것

대화와 `git log --oneline -15` · `git status --short` 에서:

```markdown
# {제목 = 주요작업}
**일시**: YYYY-MM-DD HH:MM · **브랜치**: {branch} · **범위**: {한 줄}

## 완료
- {항목} — `{주요 파일}`

## 결정과 맥락
### {결정 제목} (D번호가 있으면 함께)
- **계기**: {무엇을 하다 발견했는지}
- **대안**: {검토하고 버린 것과 이유}
(결과만 적지 않는다. 왜 이 방향인지가 다음 세션의 재논의를 막는다.)

## 트러블슈팅
- {증상} → 원인 / 해결 / 커밋 (없으면 "없음")

## 열린 질문 · 사람이 정할 것
- ...

## 다음에 할 것
1. ...
```

## 규칙

- **비밀을 쓰지 않는다**: API 키·토큰·크레딧 코드·개인 연락처는 로그에 넣지 않는다. 필요하면 "`docs/private/` 참고"로만 적는다.
- 사실만 쓴다. 하지 않은 일을 완료로 쓰지 않고, 확인 못 한 것은 "미확인"으로 쓴다.
- 이 폴더는 커밋 대상이다. 팀 개인 정보가 들어간 논의는 `docs/private/` 에 따로 쓴다.
- 저장 후 경로 한 줄만 알려준다. 커밋은 하지 않는다.
