# core/ — 도메인 무관 뼈대

미션이 정해지기 전에 완성해 두는 부분. 도메인 용어(설비·에러코드 등)를 이 안에 넣지 않는다.

| 모듈 | 책임 |
|---|---|
| `llm.py` (예정) | `https://inference.local` 로 Nemotron 호출(OpenAI 호환). 키 없음. 실패는 명시적 에러 |
| `hitl/` | draft 생성만 하는 저장소 + 사람 전용 승인·반려 전이. 신원은 서버 주입 (D2) |
| `guard/` | 업로드 문서·센서 값·웹 콘텐츠를 신뢰할 수 없는 입력으로 감싸고 주입 문장을 판정 |
| `audit/` | 도구 호출·결과 기록 (호출 직전 이벤트 발행) |
| `policy_proposer/` | 관찰 모드에서 쓴 네트워크·파일·도구만 모아 OpenShell 정책 초안 생성 → 사람 승인 |
