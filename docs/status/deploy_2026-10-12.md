## 발견

1. **Google Cloud 에서 공공데이터포털(`apis.data.go.kr`) TCP 연결이 막힌다.**
   - 진단용 Cloud Run 작업(키 없이 접속)으로 확인했다. 첫 1회는 0.4초 만에 연결(401 — 키 없음, 정상)됐고, 그 뒤로는 us-central1·asia-northeast3 모두 매번 연결 실패였다.
   - DNS 는 0.6초에 풀리고, IP(27.101.236.63)를 직접 지정해도 실패한다. 같은 시각 로컬 PC 에서는 0.07초에 연결된다.
   - 공공데이터포털 쪽 방화벽이 클라우드 출구 IP 를 막는 것으로 보인다(추정).
   - **사람 결정(2026-10-12):** 활용신청에 웹사이트 주소를 넣지 않아서일 수 있으니 "된다는 가정"으로 TourAPI 를 켠 채 둔다. 그동안 매 일정 요청이 TourAPI 5초를 기다린 뒤 "지금 확인할 수 없음"을 보인다.
   - 주소 등록 뒤에도 `timeout` 이면 배포에서 끄기(`KC_TOURAPI_DAILY_CALLS=0`) 또는 고정 출구 IP(VPC 커넥터 + Cloud NAT, 유료) 중에서 다시 정한다.
   - 진단 작업 5개는 지웠다.
2. **Netlify 새 사이트에 방문자 보호(팀 로그인)가 기본으로 켜져 있다** — 모든 경로 401. 사람이 Visitor access 를 Public 으로 바꾼다.
3. 날짜가 바뀌면 데모 캐시가 다시 LLM 을 부른다(Stage 4 발견 1). 배포 인스턴스는 `/tmp` 휘발이라 콜드 스타트 뒤에도 캐시가 비어 있다.
