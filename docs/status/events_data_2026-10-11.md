### `max_gu_dist_km` = 8 유지 (D25 ③)

구별로 모든 좌표의 중앙값까지 거리(18,967 좌표행).

- **20개 구의 p99 가 8km 이하다.** 8km 초과는 287행(1.5%)이고, 10km 초과는 106행, 20km 초과는 13행이다.
- **8km 초과 행의 대부분은 구 표기 오류다.** 종로구 8~10km 구간 134행 중 121행이 "꿈의숲 콘서트홀"이다. 이곳은 실제로 강북구에 있고, 종로구 중앙값에서 약 8.0km 떨어져 있어 걸러진다.
- **5km 로 낮추면 실제 장소를 잃는다.** 은평역사한옥박물관(은평구 진관동, 은평구 중앙값에서 약 6.6km)이 그 예다. 은평구는 5km 초과가 139행이다.
- 근거는 `auto_rules.json` 의 `note` 에 적었다.

### 이름 일치율 (정확히 같은 이름만, `PlaceBook.lookup`)

흔히 쓰는 장소 40개를 확인했다.

- **자동 좌표가 붙음:** 서울숲, 국립중앙박물관, 예술의전당, DDP, 서울시립미술관, 덕수궁, 망원한강공원, 서울식물원, 롯데콘서트홀, 서울공예박물관, 은평역사한옥박물관, 노들섬.
- **사람 사전:** 경복궁, 창덕궁, 익선동.
- **없음:** 롯데월드, 석촌호수, 잠실역, 올림픽공원, 세종문화회관, 코엑스, 동대문디자인플라자, 북서울꿈의숲, 남산서울타워, 국립민속박물관, 경희궁, 블루스퀘어, 그리고 동네 이름(홍대·이태원·성수동·문래창작촌·마곡).

없는 이유:

- 서울 API 장소명이 "세종문화회관 대극장"처럼 세부 공간까지 적혀 있어 정확한 일치가 안 된다. "세종문화회관" 이름의 행은 0건이다.
- 여의도한강공원은 2행이 453m 떨어져 있어 모호로 버려졌다(150m 기준).
- 역·동네는 행사 장소가 아니다.
- "광나루, 잠실, 뚝섬, …" 처럼 여러 장소를 한 문자열에 적은 행도 한 이름으로 채택됐다. 사용자 문장과 정확히 같을 일이 거의 없어 영향은 작다.

## 발견

1. **TourAPI 키가 카탈로그 자식 프로세스로 갈 수 있었다(고침).** `backend/catalog_runner._SOURCE_KEYS` 에 `tourapi_kto` 가 남아 있었다. 그래서 관리자 수동 수집(`admin_refresh`, `source_id=tourapi_kto`)이 키를 에이전트 역할 자식에게 넘길 수 있었다. 공개 모드에서는 관리자가 닫혀 있다. D29 ① 에 맞춰 항목을 지우고 테스트를 추가했다. 출처 목록의 `tourapi_kto` 는 `status: live_display_only` 다.
2. **데모 캐시는 날짜가 바뀌면 다시 LLM 을 부른다.** 캐시 키에 "오늘"이 들어가기 때문이다(연도 가정이 오늘에 따라 달라짐 — Sprint 3 T405). 그래서 공개 데모 직전에 그날 한 번 보내 캐시를 채워야 한다. 배포 확인(T426)의 NVIDIA 예산에 하루 1회를 넣는다.
3. **자동 좌표 장소 이름만으로는 일정 문장으로 인식되지 않는다.** "10/16에 국립중앙박물관 11시, 노들섬 3시" 는 게이트에서 일반 대화로 갔다. 게이트 조건은 날짜·시각 + (일정 어휘 또는 게이트 사전 이름)이고, 자동 사전 이름은 게이트에 넣지 않는다(D25 ⑧). "숙소는 …" 이나 "… 갈 거야" 를 붙이면 일정으로 간다(오프라인 판별로 확인). 새 구 장소로 일정을 쓰는 사용자가 어휘 없이 쓰면 일반 대화가 된다 — 이월 후보.
4. **자동 좌표의 이름 일치율이 랜드마크에서 낮다**(위 표). 세부 공간 접미사("대극장")를 떼는 별칭은 D25 ② 의 "같은 이름" 규칙을 넓히는 일이라 사람 결정이 필요하다 — 이월 후보.
5. 앵커에 구 정보가 없어 TourAPI 는 늘 서울 전체로 조회한다(T434, 명세의 폴백). 결과가 일정 장소와 먼 행사일 수 있다. 원문 절은 거리 정렬 대상이 아니다(D29: 좌표 반영 없음).
