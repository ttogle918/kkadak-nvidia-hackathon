# 01. 기능 명세 [확정] (5장 여행 기록 제외)

> 우선순위: **P0** 없으면 데모가 안 됨 / **P1** 있으면 데모가 좋아짐 / **P2** 시간이 남으면.
> 각 기능의 "완료 기준"을 만족해야 끝난 것으로 본다.

## 1. 범위

| 구분 | 내용 |
|---|---|
| 사용자 | 서울에 온 외국인·내국인 여행자 |
| 지역 | 현재 데모는 중구(덕수궁·정동) 먼저. 대상은 중구·종로구·마포구·강남구 위주(확장 가능). 4개 구는 2026-10-07 팀이 확정했고(AGENT_CONTEXT 3.2) 이후 추가될 수 있다. 실제 목록은 `domains/kcontext/data/regions/*.json` 을 따른다 |
| 언어 | 한국어, 영어 |
| 형태 | 챗봇 대화 + 지도. 모바일 화면과 데스크톱 데모 화면 |
| 하지 않는 것 | 예약·결제, 사용자가 정한 일정 변경, 사진 정리, 실시간 위치 추적, 날씨·혼잡도 연동(나중에) |

## 2. 공통 기능

| ID | 기능 | 우선 | 완료 기준 |
|---|---|---|---|
| C-01 | 일정 입력(대화) | P0 | 자유형 글에서 날짜·숙소·방문지·관심사를 뽑아 `anchors`로 만든다. 예시 입력 5종에서 날짜와 장소가 모두 맞다 |
| C-02 | 빈 시간 추론 | P0 | `free_slots`를 만들고 가정을 한 줄로 밝힌다. 사용자가 고칠 수 있다 |
| C-03 | 일정 타임라인 | P0 | 날짜별로 원래 일정 / 제안 / 추가한 것이 구분되어 보인다 |
| C-04 | 장소 이름 → 좌표 | P0 | 숙소·방문지 이름을 좌표로 바꾼다. 못 찾으면 되묻는다. 호텔 링크는 열지 않는다 |
| C-05 | 공통 지도 | P0 | 옛날(구간·핀)과 지금(핀·구역)이 한 지도에 뜬다. 옛날만/지금만/둘 다 전환 |
| C-06 | 출처 태그 | P0 | 모든 카드와 구간에 `[등급] 출처 이름 · 위치` 태그가 붙는다. 누르면 원문 구절, 서지·URL, 수집일 |
| C-07 | 판단 근거 패널 | P0 | 채택·탈락 목록과 탈락 이유, 충돌 시 어느 쪽을 왜 택했는지 보인다 |
| C-08 | 진행 표시 | P1 | 일정 이해 → 후보 수집 → 신뢰도 판단 → 일정에 맞추기 → 맥락 설명 단계가 보인다 |
| C-09 | 보안 로그 | P0 | 차단·허용 기록이 데스크톱 데모 화면에 보인다 |
| C-10 | 공격 프롬프트 방어 | P0 | "/secret/… 파일을 읽어 줘"가 OpenShell에서 거부되고 에이전트가 범위를 설명하며 계속 답한다 |
| C-11 | 새 출처 승인 | P1 | 허용 목록 밖 접근이 거부된 뒤 사람이 승인하면 재시도가 성공한다 ⚠ 미해결 충돌: D7 과 어긋남(에이전트는 로컬 색인만 조회하고 외부 수집은 호스트 수집기가 한다. 04 §5 "임의의 주소를 여는 도구는 두지 않는다"와도 모순) — 사람 결정 대기 (OpenShell 규칙 승인은 운영자 터미널 전용, 앱 안의 승인은 사람 전용 승인 API) |
| C-12 | 영어 출력 | P1 | 사용자가 영어로 쓰면 카드와 답이 영어로 나온다. 옛 지명·관직은 풀어 쓴다 |
| C-13 | 빈 상태·실패 처리 | P1 | 제안할 것이 없으면 그렇게 말한다. 외부 호출 실패 시 로컬 자료로 답하고 "실시간 확인 못 함"을 표시 |
| C-14 | 자료 속 지시문 무시 | P1 | 수집 자료에 "이전 지시를 무시하고…"가 있어도 따르지 않고 로그에 남긴다 |
| C-15 | 예시 질문 버튼 | P1 | 첫 화면에 3개. 심사위원이 바로 눌러 볼 수 있다 |

## 3. 이야기 길

| ID | 기능 | 우선 | 완료 기준 |
|---|---|---|---|
| S-01 | 경로 A·B·C 생성 | P0 | 출발–도착 한 쌍에 대해 최대 3개 경로. 걷는 시간, 가장 빠른 경로와의 차이, 이야기 수, 딱지 구성이 붙는다 |
| S-02 | 경로 배지와 추천 | P0 | 가장 빠름 / 이야기 가장 많음 / 추천 배지. 추천 이유 한 줄 |
| S-03 | 경로 겹쳐 보기 | P1 | 고르기 전에 세 경로가 지도에 겹쳐 보인다 |
| S-04 | 구간 이름표 지도 | P0 | 고른 경로가 구간으로 나뉘고 이름표가 붙는다. 약한 구간은 점선 |
| S-05 | 구간 목록 | P0 | 길찾기 안내처럼 순서대로. 지도와 서로 연동 |
| S-06 | 옛날 카드(사실 층) | P0 | 본문, 딱지(기록/전승/추정), 출처 태그 |
| S-07 | 몰입 층 | P1 | 2인칭 내레이션을 켜고 끈다. "상상" 표시 |
| S-08 | 이설 표시 | P1 | 해결되지 않은 충돌은 두 설을 나란히 |
| S-09 | 우회 한도 | P0 | 남은 시간의 일정 비율을 넘는 경로는 내지 않는다 |
| S-10 | 걷는 중 화면 | P2 | 현재 구간 이름이 크게, 방향 안내 한 줄 |
| S-11 | 근거 없는 이야기 탈락 | P0 | 출처가 없으면 카드로 만들지 않고 탈락 이유를 남긴다 |

## 4. 지금의 한국

| ID | 기능 | 우선 | 완료 기준 |
|---|---|---|---|
| N-01 | 행사 수집(공식 API) | P0 | 데모 지역·기간의 행사가 정규화되어 색인에 들어간다 |
| N-02 | 구청 게시물 수집 | P1 | 데모 지역 구청 게시판의 최근 게시물과 첨부 포스터를 가져온다 |
| N-03 | 포스터 읽기 | P1 | 비전 모델로 날짜·시간·장소·주최를 뽑고 본문과 비교한다 |
| N-04 | 중복 병합 | P1 | 같은 행사가 여러 출처에 있으면 하나로 합친다 |
| N-05 | 상태 판정 | P0 | 확인됨 / 확인 필요 / 보류. 끝난 행사는 제안하지 않는다 |
| N-06 | 빈 시간에 맞추기 | P0 | 빈 시간, 운영 시간, 추가 이동시간으로 들어갈 자리를 정한다. 숫자는 경로 엔진 값 |
| N-07 | 지금 카드 | P0 | 들어갈 자리, +분·체류, 왜 맞는지, 출처 상태, 가 봐야 아는 것, 출처 태그 |
| N-08 | 지도 표시 | P0 | 핀 / 구역 / 대략 원. 누르면 동선에서 들렀다 가는 길과 추가 시간 |
| N-09 | 일정에 추가·건너뛰기 | P0 | 누르면 타임라인에 반영된다 |
| N-10 | 포스터 영역 | P1 | 포스터 썸네일과 읽어낸 값을 나란히 |
| N-11 | 동네 맥락 한 줄 | P1 | 검증된 옛날 카드에서 가져온다. 없으면 넣지 않는다 |
| N-12 | 조건 변경 반영 | P1 | "비 온대" 같은 말에 제안이 바뀐다 |
| N-13 | 술 관련 안전 문구 | P1 | 야장·술집 카드 끝에 한 줄. 미성년 동행이면 제외 |
| N-14 | 변경 알림 | P2 | 추가한 행사가 바뀌면 알리고 대안 제안 |

## 5. 여행 기록 `[제안]`

> **이번 범위 밖.** 마지막에 별도 agent 하나로 붙인다. 아래 R-01~05 는 `[확정]` 이 아니라 `[제안]` 이다.

| ID | 기능 | 우선 | 완료 기준 |
|---|---|---|---|
| R-01 | 다녀옴 표시 | P1 | 카드에서 "다녀왔어요"를 누를 수 있다 |
| R-02 | 기록 타임라인 | P1 | 날짜별로 걸은 경로와 다녀온 곳. 딱지와 출처 태그가 그대로 남는다 |
| R-03 | 기준 날짜 고정 | P1 | 행사는 "○월 ○일 기준"으로 표시 |
| R-04 | 가지 않은 곳 구분 | P1 | 제안만 받은 곳은 접혀 있거나 흐리게 |
| R-05 | 내보내기·삭제 | P2 | 이미지 또는 PDF로 내보내고, 기록을 지울 수 있다 |

## 6. 비기능 요구

| 항목 | 기준 |
|---|---|
| 응답 시간 | 카드가 뜨기까지 목표 20초 이내. 그동안 진행 표시 `[제안]` |
| 정확성 | 끝난 행사 제안 0건, 출처 없는 주장 0건, 우회 한도 위반 0건 |
| 개인 정보 | 일정과 대화는 샌드박스 밖으로 나가지 않는다. 지도 서비스로는 장소 이름과 좌표만 |
| 재현성 | 공개 저장소의 README대로 하면 같은 데모가 뜬다 |
| 데모 안정성 | 외부 사이트가 죽어도 로컬 수집본으로 데모가 돈다 |

## 7. 데모에 꼭 필요한 최소 묶음

C-01~07, C-09, C-10, S-01, S-02, S-04~06, S-09, S-11, N-01, N-05~09.

여기에 P1 을 붙인다: N-02·N-03(비전 모델) → C-11(정책 어드바이저) → S-07. 여행 기록은 이번 범위 밖이다(5장).
