# 실록 키워드 측정·자동 후보 (T415)
상태: 확정(도구·실측) / 이용 조건 일부 [확인 필요]
도구: `domains/kcontext/ingest/sillok_keywords.py` · 확인일 2026-10-10 · 사람이 고르는 것은 H3(선택, D28)

## 하는 일과 하지 않는 일
- 도구는 **후보와 건수만 출력**한다. 지역 파일(`data/regions/*.json`)은 고치지 않는다(`--out` 이 `data/regions/*.json` 이면 거부). 어떤 후보를 `sillok_keywords` 에 넣을지는 사람이 고르고, 고른 사람·날짜·근거는 지역 파일 `note` 에 적는다(D28 ②). 고르지 않은 구는 빈 목록 = "실록 색인 대상 아님"(D28 ③).
- 일반명사 동명(방위·관청·한 글자 지명 등)은 걸러내지 않는다. 아래 "읽는 법" 의 노이즈 예를 보고 사람이 판단한다.
- 실록 XML 은 `sillok.parse_file`(D14 검사) 로만 읽는다. 읽지 못한 파일은 `_meta.skipped_files`. 기사 id 형식이 다른 38건은 세지 않는다(380,974 → 380,936).

## 명령
```
python -m domains.kcontext.ingest.sillok_keywords count --src <XML 폴더|파일> --candidates <json> [--out <json>]
python -m domains.kcontext.ingest.sillok_keywords places --src <XML> [--top 500] [--out <json>]
python -m domains.kcontext.ingest.sillok_keywords dongs --from-seoul <API 응답 json> --gu-codes <json> [--out <json>]   # 보조: 네트워크 없음
python -m domains.kcontext.ingest.sillok_keywords candidates --src <XML> --dongs <json> --readings <Unihan_Readings.txt> [--top 2000] [--out <json>]
```
- `count` 입력 `{"<region_id>": ["<한자>", ...]}` → `{"<region_id>": {"<kw>": {"title","body","articles"}}, "_meta": {files, files_read, articles, skipped_files}}`. `title`/`body` = 키워드가 제목/본문에 있는 기사 수, `articles` = 둘 중 하나. 제목은 한글 요약이라 한자 키워드는 거의 본문에서만 잡힌다.
- `places` — `<index type="지명">` 태그를 **기사 단위**로(한 기사 안 중복은 1) 센 상위 N.
- `candidates` — 상위 N 개 지명 태그를 Unihan `kHangul` 로 읽어(글자별 독음의 곱을 첫 독음 우선으로 최대 8조합, 독음 없는 글자가 있으면 건너뜀) 동 이름의 **어근**(끝의 `동`과 숫자·`제n`·`n가` 접미를 뗀 것, 예 `역삼1동`→`역삼`, `종로1·2·3·4가동`→`종로`)과 **완전 일치**하면 후보. 출력 `{"<region_id>": [{"tag","reading","dong","articles", "ambiguous"?, "count"}]}` — `articles` = 그 태그가 지명 색인으로 달린 기사 수(정렬 기준), `count` = `count` 명령과 같은 제목·본문 건수(본문 어디서든 나오는 수라 훨씬 클 수 있다), `ambiguous: true` = 같은 태그가 여러 구의 동에 걸림. 구 이름이 어느 지역 파일의 `gu` 에도 없으면 키가 구 이름이다.

### `candidates` 실측 요약 (상위 2,000 태그)
- 후보가 나온 구 20곳, 후보 행 73개(동이 여러 개인 태그는 행이 동 수만큼). 예: 종로 社稷 → 사직동(287, 본문 2,688) · 平昌 → 평창동(126); 금천 嘉山 → 가산동(312); 서대문·성북·용산 등 궁릉·지명 후보.
- **노이즈 예(사람이 걸러야 함)**: 중 `明`→명동(지명 태그 855·본문 49,223 — 나라 이름 明), 도봉 `昌`→창동(본문 16,908), 강동 `吉`→길동(13,801). 한 글자 태그와 본문 건수가 지명 태그 건수보다 훨씬 크면 일반 글자일 가능성이 높다. 반대로 `articles` 와 `count.articles` 가 비슷하면(예 嘉山 312/348) 지명으로만 쓰인 것이다.
- 한계: 독음 일치는 동 이름이 옛 지명과 같을 때만 후보가 된다(`docs/CONTEXT_STORY_ROUTE.md` 의 "행정동과 옛 지명의 불일치"). 두음법칙·옛 독음 차이(例 `류`↔`유`)는 맞추지 않아 놓치는 후보가 있다. 후보가 없는 구는 키워드 없음(색인 대상 아님)이 기본이다.
