# 실록 임베딩 시험 — 무엇을 임베딩할지, 어느 모델로 (2026-10-07, 예비 결과)

상태: **예비**. 규모가 작아 방향만 잡는다(아래 한계). T209 는 이 결과로 시작하되 모델 이름을 설정으로 빼 둔다.

## 방법
- 코퍼스: `2nd_waa_101~103.xml`(태조실록 원년 앞부분) 기사 273건(본문 60자 초과). 국역이 없어 본문은 한문이고, 한글은 제목(한 줄 요약)뿐이다(`docs/spikes/sillok.md`).
- 질문 15개(한국어) 중 정답이 3~120건인 12개 사용. **정답은 제목이 아니라 한문 본문의 정규식**(예: "정도전이 한 일" → `鄭道傳`)으로 정했다. 제목 필드에 유리하게 편향되지 않게 하려는 것이다. "일식"·"지진"은 정답 0건이라 빠졌다.
- 모델: 호출 가능한 것은 둘뿐이었다 — `nvidia/nemotron-3-embed-1b`, `nvidia/llama-nemotron-embed-vl-1b-v2`(둘 다 2048차원, `input_type` query/passage). 같은 목록의 `llama-3.2-nv-embedqa-1b-v1`·`nv-embedqa-mistral-7b-v2`·`embed-qa-4`·`llama-3.2-nemoretriever-1b-vlm-embed-v1`·`snowflake/arctic-embed-l` 은 `/v1/models` 에는 있지만 이 계정에서 404 였다.
- 임베딩 대상 4가지: 제목 / 제목+지명 태그(`index[@type=지명]`, 한자) / 본문 앞 1000자 / 제목+본문 앞 900자. 코사인 유사도.
- 기준선: 질문과 제목의 글자 3-gram 겹침(D8 의 FTS5 trigram 대용).

## 결과 (MRR · recall@10, 12개 질문 평균)
| 임베딩 대상 | nemotron-3-embed-1b | llama-nemotron-embed-vl-1b-v2 |
|---|---|---|
| 제목 | 0.668 · 0.373 | 0.821 · 0.380 |
| 제목+지명 태그 | 0.721 · 0.376 | 0.814 · 0.389 |
| 본문 앞 1000자 | 0.610 · 0.443 | 0.721 · 0.365 |
| 제목+본문 | 0.676 · **0.467** | 0.759 · **0.473** |
| (기준선) 제목 3-gram | 0.301 · 0.268 | |

## 읽는 법
- 제목만 넣으면 첫 정답은 빨리 찾지만(MRR 높음) 본문에만 나오는 기사를 놓친다(recall 낮음). 본문을 더하면 recall@10 이 두 모델 모두 가장 높다. → **청크 텍스트는 제목+본문 앞부분**을 기본으로 한다.
- 지명 태그를 텍스트에 섞는 효과는 모델마다 다르고 작다(MRR +0.05 / -0.01). 한자 지명은 한국어 질문과 맞붙기 어렵다. → 임베딩에 섞지 말고 **`place_alias`(지명 사전)로 구조화**해 지역 필터·검색어 확장에 쓴다.
- 두 모델 모두 기준선(제목 3-gram)보다 확실히 낫다. 한국어 질문 → 한문 본문이 걸리는 것은 의미 기반 검색의 이점이다.
- 모델: MRR 은 `llama-nemotron-embed-vl-1b-v2` 가 높고 recall@10 은 비슷하다. 질문 12개라 차이가 잡음일 수 있다. → 기본은 `llama-nemotron-embed-vl-1b-v2`, 모델 이름은 설정·`chunk_embeddings.model` 컬럼에 기록해 바꿀 수 있게 한다. 이름이 "vl"(멀티모달)이라 텍스트 전용 모델이 쓸 수 있게 되면 다시 본다.

## 한계 (결과를 과신하지 말 것)
- 코퍼스 273건·질문 12개·1회 실행. 신뢰구간 없음. 태조 원년 앞부분에 몰려 있어 다른 왕대·긴 기사는 확인하지 못했다.
- 정답이 정규식이라 노이즈가 있다(예: `寺`는 관청·인명에도 나온다, 정답 누락도 있다). 사람이 판정한 평가셋이 아니다.
- 국역이 없는 자료다. 국역이 생기면(다른 자료·사람 번역) 결과가 바뀔 수 있다.
- 본문은 1000자로 잘랐다(`truncate=END` 도 적용). 긴 기사는 청크 분할 뒤 재시험이 필요하다.
- 실록 본문(공공저작물 출처표시, AI 학습용 이용허락)을 NVIDIA 공개 API 로 보냈다. 공개 자료이고 키는 호스트에서만 읽었다(D1·D7). 임베딩 벡터는 커밋하지 않는다.
- **레포만으로는 수치를 재현할 수 없다.** 시험 스크립트·질문 15개·정답 정규식은 임시 폴더에서만 돌렸고 남기지 않았다. 재현하려면 위 방법을 다시 구현해야 한다.
- 시험은 본문 앞 900~1000자 1회였고, 수집기(`ingest/sillok.py`)는 본문 전체를 800자 청크로 나눠 청크마다 제목을 붙인다. 시험 조건과 구현이 다르다.
