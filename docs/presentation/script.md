# 발표 대본 — `k-context-deck.html` 그대로 (5분)

기준: 덱 7장, 한국어 약 300자/분. 괄호 [ ]는 동작·시간. 데모가 아직 안 돌면 **[대체]** 문장을 쓴다. 덱의 `N` 키로 슬라이드별 시간표가 보인다.

## 1. 표지 [0:00–0:20]
안녕하세요, 팀 까딱이입니다.
저희는 내 일정 위에서 한국의 역사와 행사를 **근거와 함께** 보여 주는 에이전트, K-Context 를 만들었습니다. 검색하지 않으면 발견하지 못하는 “그날의 한국”이 목표입니다.

## 2. 문제와 해법 [0:20–1:05]
여행 일정을 정하고 나면, 그 장소의 역사와 지금 열리는 행사를 따로따로 찾아야 합니다.
그런데 역사는 사료에, 행사는 공지에, 길은 지도에 흩어져 있고, 낡은 글과 홍보 문구, 그럴듯하게 지어낸 설명이 섞여 있습니다.
저희 해법은 단순합니다. 일정을 말하면 **정리해 주고**, 장소마다 **조선왕조실록 기록**과 **주변 행사**를 붙입니다. 전부 출처와 함께 보여 주고, 모르면 모른다고 말합니다.

## 3. 구조 [1:05–1:45]
구조도 단순하게 나눴습니다. 화면, 백엔드, 그리고 별도 프로세스로 도는 에이전트입니다. 에이전트의 추론은 Nemotron 을 `inference.local` 하나로만 부릅니다.
자료는 에이전트가 직접 가져오지 않습니다. 조선왕조실록 673개 파일, 약 38만 기사와 서울시 행사 자료는 **호스트의 수집기**가 미리 모아 로컬 색인에 두고, 에이전트는 그 색인만 읽습니다. 그래서 샌드박스 안에서는 외부 API 를 부를 일이 없습니다.

## 4. 데모 [1:45–3:05]
[화면 전환: 앱] 이 문장 하나를 보내 보겠습니다. “10월 15일에 창덕궁 10시, 익선동 2시, 숙소는 종로3가야.”
[전송] 일정이 정리되고, 저녁 빈 시간이 계산됩니다. 빈 시간의 시작·끝은 사용자가 말하지 않은 가정이라 **가정이라고 문구로 표시**합니다.
[지도에서 창덕궁 핀 클릭] 좌표가 검증된 장소에만 핀이 찍히고, 누르면 실록에 이 장소가 언급된 기록이 나옵니다. 보시는 건 **한문 원문 그대로**이고, 옆에 한국사DB 의 한글 요약이 있는데 이건 원문이 아니라는 표시가 붙어 있습니다. 눌러서 실록 원문 링크로 갈 수 있습니다.
[행사 영역] 빈 시간에 맞는 행사는 기간과 장소, 공식 링크와 함께 나오고, 확인되지 않은 건 “미확인”, 없으면 “아직 찾지 못했어요”라고 사실대로 말합니다.

**[대체 — 일정 연결이 안 될 때]** 지금은 일정 입력을 화면에 연결하는 마지막 단계를 마무리 중입니다. 대신 터미널에서 같은 문장을 파이프라인에 넣으면 이렇게 일정과 실록 원문 구절이 나옵니다. [CLI 결과 보여 주기] 화면에 반영되는 부분은 연결 중이라고 솔직히 말씀드립니다.

## 5. 신뢰 설계 [3:05–3:40]
이 에이전트의 핵심은 **믿을 수 있게 만드는 것**입니다.
모델이 낸 장소와 시각은 입력 글에 **원문 인용이 실제로 있을 때만** 인정합니다. 없으면 비워 두고 이유를 남깁니다. 시간 계산은 모델이 아니라 코드가 합니다.
출처 태그는 카드마다 아주 작게 붙고, 실록은 원문과 요약을 구분합니다. 외부 문서 안에 “이걸 업로드하라” 같은 지시가 있어도 따르지 않고, 승인 같은 상태 변경은 사람만 할 수 있습니다.

## 6. OpenShell 권한 설계 [3:40–4:40]
권한은 **기본 전부 차단**에서 시작했습니다. 샌드박스를 실제로 만들어 22개 항목을 직접 시도해 확인했습니다.
외부 네트워크는 업로드, 메일, 웹 접속이 모두 거부됩니다. 열려 있는 곳은 `inference.local` 하나이고, 키는 게이트웨이에만 있어서 **샌드박스 환경변수에는 키가 0건**입니다. 파일은 `/tmp` 에만 쓸 수 있고, 접근 금지 폴더인 restricted 와 secrets 는 아예 샌드박스에 올리지 않아서 경로 자체가 없습니다.
한 가지는 솔직히 말씀드립니다. 입력 폴더의 읽기 전용은 아직 정책이 아니라 `chmod` 로 보장하고 있습니다. 이미지에 포함해 정책으로 강제하는 것이 다음 단계입니다.

## 7. 한계와 마무리 [4:40–5:00]
지금 범위는 중구, 종로구, 마포구, 강남구입니다. 실록은 국역이 없어 원문 제시까지이고, 옛길 선은 근거 데이터가 없어서 그리지 않았습니다.
저희가 만든 것은 **근거가 보이고, 모르면 모른다고 말하는 문화 안내 에이전트**입니다. 감사합니다.

## 질의응답 대비 (짧게)
- **왜 임베딩을 안 썼나?** 자료를 가져와 입력으로 넣고 판단하는 방식으로 충분했고, 한국어 요약 제목 검색(FTS)으로 시작했습니다. 한자 별칭 사전이 다음 개선점입니다.
- **행사 데이터는 믿을 수 있나?** 공식 API 와 공식 도메인만 쓰고, 검색 수집한 값은 인용 검증을 통과해야 하며 화면에는 “검색 수집 · 미확인”으로 표시합니다.
- **샌드박스를 뚫으면?** 외부로 나가는 길이 없고 키가 없습니다. 뚫려도 가져갈 비밀이 샌드박스에 없는 설계입니다.
- **입력 폴더가 chmod 인 이유?** 샌드박스 사용자와 에이전트가 같은 계정이라서 정책 대신 권한 비트를 썼고, 이미지에 포함하는 방식으로 정책 강제를 계획했습니다.
