## Sprint 1 범위: `core/` 뼈대 (10/7 이전, 주제 무관)

### 반드시 만들 것
1. **`core/hitl`** — draft 저장소(SQLite). 승인·반려 전이는 사람 전용 함수로만 열고, 신원은 서버가 주입한다 (D2).
2. **`core/audit`** — 도구 호출·결과 기록. 호출 직전에 이벤트를 발행하고 호출 순서를 보존한다.
3. **`core/guard`** — 업로드 문서·센서 값 같은 외부 입력을 "신뢰할 수 없는 입력"으로 감싼다. 우선 규칙 기반으로 주입 문장을 판정한다.
4. **`core/policy_proposer`** — 관찰한 접속·파일·도구 기록을 입력받아 OpenShell 정책 YAML **초안**을 만든다. 사람 승인 전에는 초안이다.
   - 핵심 결정: 입력인 "관찰 기록"의 형식(OpenShell 로그 파싱 vs. 우리 `audit` 기록). 스프린트 명세에서 정하고 `reviewer` 가 확인한다.
5. *(선택, D5)* **`core/llm`** — 기능별 provider·모델 라우팅, provider 별 동시 호출 상한, 키 풀(env 변수 이름 참조). 호스트 경로만 먼저, 게이트웨이 연결은 문서 확인 후.
6. **테스트** — 위 필수 네 모듈(1~4) 각각의 단위 테스트, 그리고 쓰기 경계 테스트(도구는 draft 외에는 쓸 수 없다). `CLAUDE.md` 회귀 절의 명령으로 통과해야 한다.
