## 미션 · 한 줄 소개
**K-Context (가칭)** — "검색하지 않으면 발견하지 못하는 '그날의 한국'". 여행자의 확정 일정은 바꾸지 않고, 같은 동네의 옛날(이야기 길)과 지금(지금의 한국)을 연결해 출처·판정 근거와 함께 보여주는 에이전트. 데모 지역: 서울 4개 구 — 중구·종로구·마포구·강남구 (2026-10-07 확정).

## Sprint 1 범위: `core/` 뼈대 (10/7 이전, 주제 무관)

### 반드시 만들 것
1. **`core/hitl`** — draft 저장소(SQLite). 승인·반려 전이는 사람 전용 함수로만 열고, 신원은 서버가 주입한다 (D2).
2. **`core/audit`** — 도구 호출·결과 기록. 호출 직전에 이벤트를 발행하고 호출 순서를 보존한다.
3. **`core/guard`** — 업로드 문서·센서 값 같은 외부 입력을 "신뢰할 수 없는 입력"으로 감싼다. 우선 규칙 기반으로 주입 문장을 판정한다.
4. **`core/policy_proposer`** — 관찰한 접속·파일·도구 기록을 입력받아 OpenShell 정책 YAML **초안**을 만든다. 사람 승인 전에는 초안이다.
   - 핵심 결정: 입력인 "관찰 기록"의 형식(OpenShell 로그 파싱 vs. 우리 `audit` 기록). 스프린트 명세에서 정하고 `reviewer` 가 확인한다.
5. *(선택, D5)* **`core/llm`** — 기능별 provider·모델 라우팅, provider 별 동시 호출 상한, 키 풀(env 변수 이름 참조). 호스트 경로만 먼저, 게이트웨이 연결은 문서 확인 후.
6. **테스트** — 위 필수 네 모듈(1~4) 각각의 단위 테스트, 그리고 쓰기 경계 테스트(도구는 draft 외에는 쓸 수 없다). `CLAUDE.md` 회귀 절의 명령으로 통과해야 한다.

## Sprint 2 범위: 데이터 → 판정 → 화면 연결 (2026-10-07~)

### 반드시 만들 것
1. **프론트 `frontend/k-context/`** — 목업을 모듈형(네이티브 ES 모듈, 번들러 없음)으로 이식. mock API 로 동작, http API 로 교체 가능.
2. **자료 수집·로컬 색인** — 실록 XML(공공데이터포털) 등 S/A 자료를 청크로 나누고 출처 메타(이름·쪽수/게시일·URL·원문 구절·수집일)와 함께 색인.
3. **행사 API** — TourAPI · 서울 열린데이터광장 문화행사 수집·정규화.
4. **공통 계약 구현** — 카드·경로 JSON(AGENT_CONTEXT 3.3), 판정 형식(6장).
5. **판정 파이프라인** — 4장 규칙(등급·충돌·무관 걸러내기·주입 차단).
6. **지도** — 도보 경로(PlayMCP 카카오맵 인증 확인 후, 막히면 OSM) + 화면 연결.
7. 사람 승인 API ↔ 프론트 보안 로그 연결.

## Sprint 3 범위: 해커톤 이후 완성 — 포트폴리오 데모 (2026-10-09~)
대회는 끝났다. 완성 기준은 **로컬에서 누구나 README 대로 띄워 같은 결과를 보는 포트폴리오 데모**다. 화면에 MOCK 이 없고, 결과가 안정적이며, 품질을 숫자로 말할 수 있으면 끝이다. 기준선: `docs/status/2026-10-07_구현상태.md`.

### 반드시 만들 것 (우선순위 순)
1. **안정성 + 평가셋** — 같은 일정 문장이 같은 결과를 내게 한다(모델 출력 변동·60초 타임아웃 대응). `eval/` 에 정답이 붙은 평가 세트와 실행기를 두고, 일정 이해·실록 언급·판정의 지표를 수치로 남긴다. 이 수치가 이후 변경의 회귀 기준이 된다.
2. **MOCK 제거** — 경로 A·B·C, 옛날 카드, 판단 근거를 실제 API·데이터로 바꾼다(`/api/itinerary`·`routes` 등). 근거가 없으면 지어내지 않고 "없음/모름"으로 보여 준다. `?api=mock` 데모 모드는 남긴다.
3. **행사 실데이터** — 서울 열린데이터광장 키 또는 Tavily 수집(D12)으로 4개 구 행사를 실제로 채운다. 출처·수집일 표시와 "모르면 모른다"(D13)는 유지한다.
4. 위에 맞춰 README·상태 문서·데모 GIF 를 갱신한다.
