## 표기

- `[확정]` 팀이 정한 것. 임의로 바꾸지 않는다.
- `[제안]` 이 문서에서 제안한 설계. 구현하면서 바꿀 수 있다.
- `[확인 필요]` 구현 전에 직접 확인해야 하는 것(주소, 버전, 이용 조건 등).
- `[검증 필요]` 자료로 확인하기 전에는 사용자에게 내보내면 안 되는 내용.

## 기능 한눈에 (이야기 길·지금의 한국이 이번 범위)

1. **이야기 길** — 목적지까지 가는 길을 A·B·C로 비교하고, 고른 길을 구간 이름표가 붙은 길찾기로 보여준다.
2. **지금의 한국** — 그날 그 동네에서만 가능한 경험을 기존 일정의 빈 시간에 끼워 넣을 것을 제안하고, 지도에 위치를 보여준다.
3. **여행 기록** `[제안]` — 여행이 끝난 뒤 다녀온 곳을 타임라인으로 돌아본다. **이번 범위 밖.** 마지막에 별도 agent 하나로 붙인다.

공통: 챗봇 대화로 일정 입력, 한 지도에 옛날과 지금, 모든 주장에 출처 태그, 판단 근거 패널, OpenShell 보안 로그.
