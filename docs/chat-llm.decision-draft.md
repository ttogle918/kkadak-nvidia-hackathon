# (결정 번호 미정) 초안 — 챗봇 최소판의 LLM 호출 방식 (번호·병합은 사람이 정한다)

상태: 초안. `docs/DECISIONS.md` 에는 아직 넣지 않았다. 팀원이 다른 D 번호를 쓸 수 있으니 사람이 번호를 정해 합친다.

## 결정
- 챗봇 최소판은 호스트 backend 프로세스가 `core.llm` 으로 NVIDIA 공개 API(`https://integrate.api.nvidia.com/v1`)를 직접 호출한다. D5 의 호스트 경로다.
- 설정은 `deploy/llm.chat.yaml`, 모델은 env `CHAT_MODEL` 로 덮어쓴다. 키는 env 변수 이름만 설정에 두고, 값은 셸 env 또는 `.env` 허용 목록 로더로만 읽는다.
- B2 보수안(사람 결정): 시스템 프롬프트에서 구체 연도·인명·수치·건축 시기·'~사건' 단정을 금지하고, 서버가 정상 답 끝에 고정 문구(`UNVERIFIED_NOTICE`)를 붙인다. 차단 응답에는 붙이지 않는다. 문구는 LLM 이 만들지 않는다. `max_tokens` 는 2048 에서 600 으로 낮췄다(`CHAT_MAX_TOKENS`).

## D10 파이프라인 경로와의 관계
- 현재는 두 경로가 공존한다: 파이프라인(D10)과 이 챗봇 호출. 임시 공존인지, 챗봇을 파이프라인으로 대체하는지는 **[사람 결정]**.

## 샌드박스에 배치할 때
- base_url 만 `https://inference.local/v1` 로 바꾸면 되지 않는다. 설정이 `api_key_envs` 를 필수로 요구해서, 키가 없는 샌드박스에서는 `ChatUnavailable` → 503 `llm_unavailable` 이 된다.
- 게이트웨이 provider 모드(키 없이 inference.local 에 맡기는 방식)는 미구현이다. 구현 방법은 [확인 필요] (nemoclaw-docs 로 확인).

## 알려진 한계
- 대화 기록이 프로세스 전역 하나라 모든 사용자가 같은 기록을 공유한다(W6 맥락). 세션 분리는 별도 결정이 필요하다. 이번에는 Content-Type 이 application/json 이 아니면 422 `bad_text` 로 거절하는 것까지만 했다(415 는 새 오류 코드라 계약 변경이 필요해 피했다).
- 로컬 백엔드 base_url 의 루프백 제한은 미구현이다(D6 한계, W2).
- audit 파일이 재시작마다 새로 생긴다(`backend-chat-<8자>.jsonl`, W8). 보관·정리 정책은 없다.
- 근거(색인) 없이 모델 기억으로만 답한다. 프롬프트와 고정 문구는 환각을 줄이는 완화책이지 보증이 아니다.
- `max_tokens=600` 은 reasoning 모델(gpt-oss-20b)에서 추론 토큰이 한도를 먹어 content 가 빌 수 있다. 빈 응답은 502 가 되고 서버 로그에 finish_reason 만 남는다(W9). 실제 빈도는 **[확인 필요]**.

## 문서 변경 요청 (이 작업에서는 고치지 않음)
- `docs/sprints/sprint-2.md` §5.1 와 `docs/07_API_SPEC.md` 에 오류 코드 `503 llm_unavailable` 추가(키 없음·설정 오류). 프론트는 이미 이 코드를 안다.
- `docs/AGENT_CONTEXT.md` Message 계약: 정상 agent reply 의 `text` 끝에 서버 고정 문구가 붙는다는 점을 명시. 장기적으로는 reply 에 `unverified: true` 필드를 추가하고 문구는 프론트 i18n 에서 렌더하는 편이 낫다(이번에는 계약을 바꾸지 않으려고 문구 방식을 택했다). 현재 문구는 ko 만 text 에 붙고 en 은 상수로만 있다.

## 모델 선택 근거
- 기본 `openai/gpt-oss-20b`. 사람이 실측한 바로는 의도 분류가 5초대였고, 함정 질문에 '확인되지 않는다'로 답했다. 후보 중 일부는 404 또는 타임아웃이었다. 각 후보의 이름·수치는 이 문서에 옮기지 않았다 **[확인 필요]**(측정 기록 위치).
- `/v1/models` 목록에 기본 모델이 있음은 2026-10-07 에 확인했다(`deploy/llm.chat.yaml` 주석).
